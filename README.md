# Dotfiles

My dotfiles for macOS

### Installation

1. Clone this repo `git clone git@github.com:austenc/dotfiles.git ~/Code/dotfiles`
2. `cd ~/Code/dotfiles` **these dotfiles assume they're in that folder**
3. Run `./setup.zsh`
4. Restart any terminals, run `p10k configure` and install the suggested font.

Skills and user-level agent rules live in [`agents/`](agents/README.md) and are symlinked by `setup.zsh`.

Enjoy! ✌️
