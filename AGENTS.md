# Dotfiles conventions

Read [agents/AGENTS.md](agents/AGENTS.md) for personal rules and source locations.
Keep portable personal skills in `agents/skills/`; the existing linker exposes
that single source to both Codex and Cursor. Avoid agent-specific tool names
in the game skills.

# Small mobile game studio

Apply these principles when designing games or maintaining the game skills:

1. Prioritize novel mechanics, then immediate comprehension, satisfying feel,
   strong visual identity, and small scope.
2. Prove the core action is enjoyable before adding menus, content, or progression.
3. Avoid cloning an existing game with a new theme or hiding weak mechanics
   behind progression and unlocks.
4. Start with a prototype one developer can build in at most two days.
   Test whether players understand the action within five seconds and want to repeat it.
5. Let depth come from mastery and interacting rules; cut features that do not
   strengthen the core loop.
